## v7.0 요약

- **레버리지 선택**: 30x / 50x
- **마일스톤 기준**: 30x → +7% ROE, 50x → +10% ROE (인풋으로 변경 가능)
- **순수익 기준 옵션**: 수수료·슬리피지를 임계값과 실현 ROE에 반영
- **청산 리스크 표시**: 청산 추정가 라인 + 손절거리 > 청산거리 경고
- **리페인팅 방지**: 봉 마감 확정 후 시그널 (기본 ON)
- **알림 7종**: 진입 / 마일스톤 / 종료 / 청산 위험

## 사용 시 주의

- 마일스톤은 **목표 도달 표식**이며 청산 신호가 아닙니다.
- 필요 가격변동이 0.2~0.35% 수준이므로 **저타임프레임(5분~1시간)** 전용입니다. 일봉에서는 의미가 없습니다.
- 고배율에서는 슈퍼트렌드 손절선이 청산가보다 멀 수 있습니다. 지표의 경고 배경이 켜지면
  승수·타임프레임·레버리지 조합을 재검토하세요.
- 수수료·슬리피지·유지증거금률 기본값은 바이낸스 USDT 무기한선물 기준 추정치입니다.
  실제 거래소 값으로 조정해서 쓰세요.
- 투자 권유가 아닙니다. 모든 매매 판단과 손실 책임은 사용자에게 있습니다.
