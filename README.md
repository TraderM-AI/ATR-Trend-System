## v7.0 요약

- **레버리지 선택**: 30x / 50x
- **마일스톤**: 30x → +7% ROE, 50x → +10% ROE (인풋으로 변경 가능, 포지션당 1회)
- **리페인팅 방지**: 봉 마감 확정 후 시그널 (기본 ON)
- **버그 수정**: 워밍업 구간 추세 오판, 진입 봉 마일스톤 오탐, 상태 리셋 누락, 표식 중첩
- **알림 6종**: 진입 2 / 마일스톤 2 / 종료 2

## 레버리지별 기준값

| 항목 | 30x | 50x |
|---|---|---|
| 마일스톤 ROE | +7% | +10% |
| 필요 가격변동 | 0.233% | 0.200% |

`필요 가격변동 = (목표ROE / 레버리지) / 100`

## 사용 시 주의

- 마일스톤은 **목표 ROE 도달 표식**이며 익절·청산 신호가 아닙니다.
  수수료·슬리피지를 반영하지 않은 **총수익(gross) 기준**입니다.
- 필요 가격변동이 0.2~0.24% 수준이므로 **저타임프레임(5분~1시간)** 전용입니다.
  일봉에서는 의미가 없습니다.
- 30배 +7%가 50배 +10%보다 더 큰 가격 변동(0.233% vs 0.200%)을 요구합니다.
- 투자 권유가 아닙니다. 모든 매매 판단과 손실 책임은 사용자에게 있습니다.
